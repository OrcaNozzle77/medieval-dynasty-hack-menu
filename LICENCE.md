## 🧩 About

**Medieval Dynasty overlay** is a curated list of Medieval Dynasty open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, map overlay
- **Quality-of-Life Helpers** — inventory catalog, crafting notes, overlay helpers
- **Research Notes** — building layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Resource overlay — visualize nearby resources and loot
- Map Overlay — display points of interest and player position
- Inventory Notes — organize items and crafting materials
- Time Control — adjust day/night cycle for study (0.1x to 5x)

### 🏗️ Building & Crafting
- Building Catalog — browse building types and requirements
- Crafting Notes — recipe lists and material costs
- Fast Craft — speed up crafting for testing

### 🏋️ Quality of Life
- Stamina Notes — track and manage stamina usage
- Weight Limit — adjust carry capacity for testing
- Skill Tracker — monitor skill progress
